Talking AI Avatar

-Eine Webanwendung mit React, in der ein digitaler Avatar einen eingegebenen Text laut vorliest.

Projektbeschreibung
Der Benutzer kann:

einen Avatar auswählen (Max, Anna, Prof. Otto)
einen Text schreiben
eine Stimme auswählen
die Sprechgeschwindigkeit einstellen
den Avatar sprechen lassen (Start, Pause, Weiter, Stop)
Während der Avatar spricht, wird er animiert (Mund bewegt sich, Avatar leuchtet und wird größer, Sprechblase erscheint).

Verwendete Technologien
React
Vite
JavaScript
Tailwind CSS
Bootstrap
Web Speech API
